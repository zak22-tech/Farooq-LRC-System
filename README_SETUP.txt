إعداد لوحة الإدارة:
1) من Firebase Console افتح Authentication ثم Sign-in method وفعل Email/Password.
2) من Authentication > Users أنشئ حساب المدير يدويا. لا توجد صفحة تسجيل حسابات داخل الموقع.
3) انشر ملف firestore.rules المرفق من قسم Firestore Database > Rules.
4) ارفع جميع الملفات في المجلد نفسه إلى الاستضافة.
5) افتح admin-login.html أو اضغط رابط الإدارة الخافت في تذييل الصفحة.

ملاحظات الأمان والتنبيهات:
- لوحة الإدارة لا تفتح إلا بعد مصادقة Firebase.
- قواعد Firestore تسمح للزوار بإضافة حجز واحد فقط، بينما التعديل والحذف والإغلاقات وبيانات المسؤولين تتطلب حسابا مصادقا.
- حفظ أرقام واتساب والبريد متاح في اللوحة. الإرسال التلقائي الحقيقي يحتاج خدمة خادم موثوقة مثل Cloud Functions مع مزود بريد/WhatsApp API، لذلك لم توضع مفاتيح سرية داخل المتصفح. يمكن إضافة هذه الخدمة لاحقا دون تغيير الواجهة.
- خيار PDF يعمل عبر نافذة الطباعة في المتصفح ثم اختيار Save as PDF.
